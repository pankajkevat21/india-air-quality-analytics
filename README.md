# india-air-quality-analytics
End-to-end data analytics project on 5 years of India AQI data (2015–2020, 26 cities). Includes data cleaning, SQL analysis, EDA visualizations, Random Forest AQI prediction, Power BI dashboard &amp; Streamlit app.
## Step 1: Data Understanding

- Dataset: Air Quality Data in India
- - Daily records: 29,531 across 26 cities
- Cities: 26
- Date range: 2015-01-01 to 2020-07-01
- Target: AQI
